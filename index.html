Cable ampacity calculator: verification case study

A cable current-rating tool built on IEC 60287, and how its results have been checked against independent hand calculations and published cases.

Verification in progress. Results are checked against hand calculations and published cases. A broader cross-check against commercial cable-rating software is still in progress; so far it covers only a few published cases. The tool is not a substitute for review by a licensed engineer.

What the tool does

It calculates the continuous current rating (ampacity) of power cables following IEC 60287, checked against published cases from 30 kV to 400 kV,, with Neher-McGrath (1957) available as an alternative method.

  • InstallationsDirectly buried cables, ducts, concrete duct banks with backfill, layered soil
  • InteractionsCrossing heat sources and several circuits with unequal loads
  • Cyclic ratingsDaily load-cycle ratings (IEC 60853-2); duct banks through a numerical model, not yet checked against a published case
  • Ground modelA numerical ground model for soil zones, and a route view
  • InterfacesA website, plus a Claude skill with calculation tools

Independent recalculation

118 cases were recalculated with a standalone script that uses no engine code: a second implementation of the same equations. The results were then added as regression tests. Most of these rows have no published value, so they check the implementation, not the method.
